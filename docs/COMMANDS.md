# Commands

Every action in the GUI is one `gpuwm-cm1` command, and **Show command** beside a button prints the exact line
before you press it. The server runs that same line and appends it to the run folder's `commands.log`, so a GUI
session can be replayed from a terminal. This page lists every command the GUI can print, in the order of its API
table (`cm1core.gui.commands.API`); upper-case words are filled in by the screen. It is generated by
`tools/release/commands_page.py`, and a test fails if it falls behind.

| Where in the GUI | Command | What it does |
|---|---|---|
| The Guided \| Advanced switch at the top | `gpuwm-cm1 gui --mode MODE` | Stores the view per OS user; no run directory changes. |
| New run: From a CM1 namelist, or From example | `gpuwm-cm1 import NAMELIST [--sounding FILE] --out RUNDIR [--acknowledge-output-keys] --json` |  |
| Domain and time, Settings: Save | `gpuwm-cm1 edit RUNDIR [--set KEY=VALUE ...] [--setting TABLE.KEY=VALUE ...] [--reset-setting TABLE.KEY ...] --json` | Domain and time, Settings: changes namelist words in place, or the values CM1 keeps in Fortran; then checks the run again. |
| Domain and time: Use the recommended frame and bubble | `gpuwm-cm1 edit RUNDIR --set umove=U --set vmove=V --setting initialization.bubble_center_x_m=X --setting initialization.bubble_center_y_m=Y --json` | Domain and time: Use the recommended frame and bubble (from the estimate's storm-track check). With CM1's updraft nudging (iinit = 12) the push is moved instead: --setting initialization.xc_wnudge=X --setting initialization.yc_wnudge=Y. |
| Namelist (advanced): Save | `gpuwm-cm1 edit RUNDIR --from EDITED_NAMELIST --json` | Check: the namelist editor's Save; the diff against your original file is kept. |
| Check: Run without these settings | `gpuwm-cm1 edit RUNDIR --acknowledge-output-keys --json` | Check: Run without the settings GM1 does not read (and ptype = 3 with --acknowledge-thompson). |
| Sounding: a new input_sounding | `gpuwm-cm1 edit RUNDIR --sounding FILE --json` | Sounding: a new input_sounding (isnd = 7 or 17). |
| Check: Check again | `gpuwm-cm1 check RUNDIR/deck.toml --json` |  |
| Domain and time: the plan map | `gpuwm-cm1 cartesian RUNDIR/deck.toml --plan --output RUNDIR/plan-receipt.json [--sounding RUNDIR/input_sounding]` |  |
| Estimate | `gpuwm-cm1 estimate RUNDIR [--gpu N] --json` |  |
| Estimate: Measure speed | `gpuwm-cm1 estimate RUNDIR --measure --json` | Estimate: Measure speed runs a few steps on the GPU (about a minute) and keeps the measured rate. |
| Estimate, Continue or extend: Copy job script | `gpuwm-cm1 jobscript RUNDIR --scheduler slurm\|pbs [--time HH:MM:SS] [--partition P] [--account A] [--qos Q] [--mem 32G] [--gpu-type T] [--cpus N] [--until SECONDS] [--setup LINE ...] [--python PY] [--write] --json` | Estimate, and Continue or extend: a job script for a cluster. It runs gpuwm-cm1 run RUNDIR --continue, so submitting it again continues from the last restart; the two sidecars run on the GPU node's CPUs. |
| Estimate: Start; guided: Start | `gpuwm-cm1 run RUNDIR` | Local runs also get the cm1out and quicklook sidecars (nice 19, no GPU). |
| Results: Continue or extend; guided: Run it 1 hour longer | `gpuwm-cm1 resume RUNDIR [--from-restart N] [--from-segment K] [--until SECONDS]` | Continue or extend: from a restart to timax, or to a later storm time; a new segment. |
| Run: Stop; guided: Stop | `gpuwm-cm1 stop RUNDIR` | A local run that has not ended 30 s later gets gpuwm-cm1 stop RUNDIR --terminate. |
| Run: Pause at next restart | `gpuwm-cm1 pause RUNDIR` |  |
| Run: Force stop | `gpuwm-cm1 stop RUNDIR --force` | Offered 60 s after Stop, for runs on this computer. |
| Results: the field list for slices | `gpuwm-cm1 quicklook RUNDIR --fields [--time S] --json` | The cm1out fields a slice can show, with their levels; reads the frame only. |
| Results: a horizontal slice | `gpuwm-cm1 quicklook RUNDIR --slice FIELD [--height M \| --level K] [--line XA YA XB YB] [--time S] --json` | Draws RUNDIR/quicklook/slices/slice-*.png on the CPU at nice 19. |
| Results: a vertical section along a drawn line | `gpuwm-cm1 quicklook RUNDIR --section FIELD --from XA YA --to XB YB [--top M] [--time S] --json` | Draws RUNDIR/quicklook/slices/section-*.png on the CPU at nice 19. |
| Results: click a column for its skew-T | `gpuwm-cm1 quicklook RUNDIR --column [--at X Y] [--time S] --json` | Draws RUNDIR/quicklook/slices/column-*.png, the skew-T of one column, on the CPU at nice 19. |
| Results: Convert again | `gpuwm-cm1 cm1out RUNDIR --force [--format nc\|grads]` | Results: Convert again, once the run has ended; on the CPU at nice 19 with no GPU. |
| Results: Reproduce bundle | `gpuwm-cm1 reproduce RUNDIR --json` | Results: Reproduce bundle, RUNDIR/reproduce/ and a .tar.gz of the namelist, sounding, report, settings, deck, receipts and versions. |
| Results: Save as film, Make the film (and Stop) | `gpuwm-cm1 quicklook RUNDIR --film LOOK [--format apng\|mp4\|gif] [--fps N] [--between K] --json` | Results: Save as film, on the CPU at nice 19 with no GPU, written to RUNDIR/quicklook/films/LOOK/; {look, stop: true} stops a film this GUI started. |
| Results: More looks, a look drawn once per run (Draw the new looks) | `gpuwm-cm1 quicklook RUNDIR --look environment\|parcels --json` | Results: draw a look that is drawn once per run now; {look: "all"} launches gpuwm-cm1 quicklook RUNDIR (the looks a run's pictures do not have yet). |
| Guided: How long can it run? (the three buttons) | `gpuwm-cm1 preset fit PRESET --budget 10m\|1h\|overnight [--sounding FILE \| --instability I --shear S --hodograph curved\|straight] [--custom KNOB=VALUE ...] [--gpu N] --root ROOT --json` | Changes nothing: the storm Start would make on this GPU, for this time. |
| Guided: Start | `gpuwm-cm1 preset new PRESET --budget 10m\|1h\|overnight --root ROOT --name NAME [--sounding FILE \| --instability I --shear S --hodograph curved\|straight] [--custom KNOB=VALUE ...] [--gpu N] --json` | Then gpuwm-cm1 run ROOT/NAME, with the sidecars, as Start does; the reply's command has both lines. |
| New run: Start from a preset; guided Customize: All settings (Advanced) | `gpuwm-cm1 preset new PRESET --budget 10m\|1h\|overnight --root ROOT --name NAME [--instability I --shear S --hodograph curved\|straight] [--custom KNOB=VALUE ...] [--gpu N] --json` | New run, Start from a preset: the preset fitted to this GPU and time, as a run folder to edit; nothing runs. A choice guided Customize greys (WSM6, Thompson, ground friction) is then set with gpuwm-cm1 edit ROOT/NAME --set ptype=7 (or ptype=3; or bbc=3, sfcmodel=1, cecd=1) --json. |
| New run: From a WRF or ArWen run, Read the file; guided: Use a sounding from my WRF or ArWen run | `gpuwm-cm1 sounding times FILE [--time T \| --record N] --map shear\|cape --map-png PNG --json` | From a WRF or ArWen run: what the file is, its times, and the domain map (0-6 km shear or CAPE). |
| From a WRF or ArWen run: click the map, or Show this spot | `gpuwm-cm1 sounding from-wrf FILE [--time T \| --record N] (--at=LAT,LON \| --ij I,J) --out FILE --map shear\|cape --map-png PNG --preview-png PNG --json` | The column at the point as input_sounding, with its skew-T and hodograph; nothing runs. |
| From a WRF or ArWen run: Import and check; guided: Next: how long can it run? | `gpuwm-cm1 import NAMELIST --wrf FILE [--wrf-time T] (--wrf-at=LAT,LON \| --wrf-ij I,J) [--wrf-frame follow] --out RUNDIR --json \| gpuwm-cm1 sounding from-wrf FILE ... --out FILE --json` | target import: a run folder from a namelist with the column as its sounding (isnd = 7); target guided: the column kept for the gallery's storm, then How long can it run? |
| Downscale (3D): Open | `gpuwm-cm1 chain inspect FILES\|DIR --map-png PNG [--map-time T] --json` | Downscale (3D): what the history is (saved times, grid, microphysics, ground) and its map. |
| Downscale (3D): Check | `gpuwm-cm1 chain check --history FILES\|DIR --window I0,J0,NI,NJ --ratio R [--start T] [--end T] [--every S] [--scheme S] [--moisture vapour-only] --json` | Downscale (3D): every admission check in plain words, and what the run would take; nothing is written. |
| Downscale (3D): Make the run | `gpuwm-cm1 chain new --history FILES\|DIR --window I0,J0,NI,NJ --ratio R [--start T] [--end T] [--every S] [--scheme S] [--moisture vapour-only] --out RUNDIR [--namelist FILE] --json` | Downscale (3D): prepares the box from the history and writes a run folder; Start runs it as any run. |

## Beside every local run

**Start** and **Continue** on this computer also start two helpers on the CPU (nice 19, no GPU), which stop when the
run ends; a cluster job script starts the same two on the GPU node:

| Helper | Command |
|---|---|
| The CM1-format writer | `gpuwm-cm1 cm1out RUNDIR --follow` |
| The pictures | `gpuwm-cm1 quicklook RUNDIR --follow` |

## Also on the command line

| Command | What it does |
|---|---|
| `gpuwm-cm1 gui [--root FOLDER] [--mode guided\|advanced] [--no-browser]` | Open the GUI (a link on 127.0.0.1 with a token, opened in your browser when this computer has a screen) |
| `gpuwm-cm1 doctor --plain` | Is this computer ready: the System screen |
| `gpuwm-cm1 doctor --report` | The same check with the versions, as one block to paste into a bug report |
| `gpuwm-cm1 status RUNDIR [--wait] [--json]` | What a run is doing: the Runs screen; `--wait` answers once it has ended or paused |
| `gpuwm-cm1 examples --cm1 [CASE] [--copy DIR]` | CM1's supercell and squall-line namelists, unchanged |
| `gpuwm-cm1 preset list` / `preset show ID` | The guided presets and whether each is offered here |
| `gpuwm-cm1 preset environment --instability I --shear S [--hodograph curved\|straight] [--out FILE]` | Make your own environment: the sounding the card's two sliders make, the model's own CAPE and shear for it, and which storm such air usually makes |
| `gpuwm-cm1 run RUNDIR [--until T] [--detach]` | Start a run from a terminal (the GUI's Start adds the two helpers) |
